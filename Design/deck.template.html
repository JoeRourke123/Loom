The system

One grid · one palette

Every keyline is derived from the 1024 px canvas by a power of φ, so the whole set has a single number in it. Nothing is nudged by eye.

C = 1024
Canvas. Apple's icon square.
M = C / φ⁵ = 92
Margin. Content keeps clear of the Liquid Glass mask.
L = C − 2M = 840
Live area. Where a mark is allowed to live.
K = L / 2 = 420
Keyline circle. Round marks are cut to it.
U = C / 64 = 16
Base unit. Every stroke weight is a multiple.
|2x/C|⁵ + |2y/C|⁵ = 1
The mask. A Lamé superellipse; Apple's shipping template measures at k ≈ 5.2, so k = 5 is inside a tenth of a percent.

Palette · warp and weft

On a loom the warp is fixed and the weft is the thread that travels. The palette keeps that division: cool holds the structure, warm does the work. No icon uses a third accent unless the equation itself has three parts.

Appearance

Six modes, one silhouette

iOS 26 renders an icon in Default, Dark, Clear Light, Clear Dark, Tinted Light and Tinted Dark. Icon Composer derives all six from three source layers. The silhouette must survive every one, which is why the meaning is always carried by the form and never by the colour.

The plates

18 marks · 5 families

Each plate names the equation it plots. If the equation changes, the mark changes — that is the whole discipline. Small previews are 52, 34 and 22 px so you can judge what survives a home screen before you commit.

Using these

Icon Composer · files · caveats

Into Icon Composer

  • Open Icon Composer (ships with Xcode 26) and make a new document.
  • Drag layers/<name>-bg.svg into the background group, -mid.svg into the mid-ground, -fg.svg into the foreground.
  • Leave shadow, highlight and blur off. The system lights the icon at runtime; anything baked in will fight it.
  • Check all six appearances, then export a single .icon into Loom/Assets.xcassets.

Honest caveats

  • Harmonograph, chladni and two-source are gorgeous at 1024 and turn to mush at 40. Use them for marketing, not the home screen.
  • Moiré is a real interference pattern, which means it will alias on some displays. That is the honest behaviour of the thing, but test it.
  • The default variant carries a background gradient. Icon Composer supports gradient backgrounds, but if you want a flat ground, take the top stop from the palette above.
  • Mono is authored the way the Clear and Tinted modes read it: white is opaque, black is transparent.
Regenerate any time with python3 Design/make_icons.py. Change a constant, get a different icon — the file is the design system, not a record of it.
